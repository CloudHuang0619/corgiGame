# 柯基動畫素材：產圖規格

這份是給圖像生成模型（Gemini / ChatGPT 等）的指示。直接複製「提示詞」那一段貼過去即可。

## 為什麼要重產

目前的三張素材是**分三次產的**，每一次的角色比例與裁切都不同：

| 段落 | 原始單格 | 柯基在格內的高度佔比 |
| --- | --- | --- |
| START | 362×339 | 83% |
| IDLE | 181×194 | 96% |
| LOOP | 362×181 | 60% |

播放時三段接力，柯基就會忽大忽小、位置忽高忽低。後製只能逼近，不能修好 ——
因為 LOOP 的身體在原圖裡本來就被裁掉比較多，那些像素不存在。

**根治的方法：三段畫在同一張圖上。** 同一張圖裡的角色比例天然一致，不需要任何對齊處理。

## 提示詞（直接複製這一段）

```
請畫一張柯基的 sprite sheet（逐格動畫表），用於手機益智遊戲。

【畫面內容】
一隻柯基趴在窗台上往外看：只看得到頭、胸口和搭在窗台邊緣的兩隻前腳，
身體下半部被畫面下緣切掉。正面視角。

【畫風】
手繪水彩風，柔和的暖橘與奶油白毛色，細的暖棕色描邊（不要粗黑框），
小圓點眼睛不加高光，表情溫和。整體乾淨、討喜、貼紙感。

【版面：這是最重要的部分，請嚴格遵守】
- 一張圖，8 欄 × 6 排 = 48 格，由左至右、由上而下依序排列
- 每格都是正方形，且大小完全相同
- 整張圖背景完全透明（PNG-32），不要白底
- 不要畫任何格線、外框、編號、標題或說明文字
- 圖片邊緣要切齊格線，四周不留多餘空白
- 建議尺寸：每格 256×256，整張 2048×1536

【一致性：這是第二重要的部分】
- 48 格裡的柯基必須是「同一隻、同一個比例」，頭的大小在每一格都一樣
- 窗台的高度在每一格都固定在同一條水平線上
- 柯基的左右位置固定置中，不要有格與格之間的左右漂移
- 只有「動作」在變，「取景」不要變

【48 格的內容，依序】
第 1–12 格　START（登場）
  柯基從畫面下方升起：第 1 格只露出兩個耳朵尖，逐格往上升，
  到第 5 格露出完整的頭與兩隻前腳搭上窗台。
  第 6–8 格開心地吐一下舌頭，第 9–12 格把舌頭收回、回到平靜表情。

第 13–24 格　IDLE（待機）
  幾乎不動的呼吸循環：胸口極輕微起伏，中間眨一次眼。
  第 24 格要能無縫接回第 13 格。

第 25–48 格　LOOP（嗅聞）
  第 25–30 格：抬頭往上嗅，鼻子微微抽動。
  第 31–36 格：頭轉向左邊嗅。
  第 37–42 格：頭轉回正面。
  第 43–48 格：回到與第 13 格相同的平靜姿勢，才能接回 IDLE。

【再次強調】
不要格線、不要編號、不要文字、背景透明、每格等大正方形、
柯基比例與窗台高度在 48 格中完全一致。
```

## 收到圖之後

1. 把檔案存成 `art/raw/corgi-all.png`
2. 跑分割與校正：

   ```bash
   python scripts/normalize-sprites.py --single art/raw/corgi-all.png --cols 8 --rows 6
   ```

3. 確認 `src/ui/sprites.ts` 的 `frames` 與實際格數一致（12 / 12 / 24）

## 驗收清單

拿到圖先檢查這幾項，任何一項不過就重產，不要勉強後製：

- [ ] 背景是透明的（不是白色）
- [ ] 沒有格線、編號、標題
- [ ] 每格等大、正方形，邊緣切齊
- [ ] 48 格數量正確
- [ ] 隨便挑三格疊起來看，柯基的頭一樣大
- [ ] 窗台那條線在每一格都在同一高度

## 如果模型做不到一張 48 格

多數圖像模型在單張圖裡畫 48 個一致的角色會力不從心。退而求其次，可以分三次產，
但**每次都要附上同一張參考圖**（例如第一次產出的第 13 格），並在提示詞加上：

```
請嚴格參照附圖的柯基：同樣的比例、同樣的頭部大小、窗台在同樣的高度。
只改變動作，不要改變取景與大小。
```

分三次產的話，格數分別是 6×2、6×2、6×4，並沿用上面的版面與一致性要求。
