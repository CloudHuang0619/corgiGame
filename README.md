# Corgidoku 柯基數獨

柯基主題的邏輯益智遊戲。規則與 LinkedIn Queens／Meowdoku 同源，但**沒有數字**：

1. 每個彩色區域恰好一隻柯基
2. 每一橫列恰好一隻
3. 每一直欄恰好一隻
4. 任兩隻柯基不得在周圍八格內相鄰（含對角線）

每一關都保證**唯一解**，可以純靠排除法推出來，不需要猜。

放下的柯基如果不在正解上，會立刻變成紅色叉號並**扣一根骨頭**。每關三根，用完就得重來——所以這遊戲懲罰亂猜，獎勵先把不可能的位置標掉。

## 開始開發

```bash
npm install
npm run dev
```

其他指令：

| 指令 | 用途 |
| --- | --- |
| `npm run dev` | 開發伺服器（<http://localhost:5173>） |
| `npm run build` | 產出 `dist/` |
| `npm run typecheck` | 型別檢查 |
| `npm run levels` | 重新產生關卡表（`-- --count 60` 可指定關卡數） |
| `npm run verify` | 把關卡表每一關重新驗證一次 |

> Node 已安裝在 `C:\Program Files\nodejs\`。若終端機找不到 `npm`，是該 shell 開啟時還沒吃到系統 PATH，重開一個終端機即可。

## 柯基的美術與動畫

盤面上的柯基會播三段動畫：

| 段 | 排版 | 影格 | 長度 | 內容 |
| --- | --- | --- | --- | --- |
| START | 6×2 | 12 | 0.5s | 從格子下方彈出、吐一下舌頭。放下柯基時播一次 |
| IDLE | 12×1 | 12 | 1.0s | 待機 |
| LOOP | 6×4 | 24 | 1.5s | 嗅聞 |

播放順序是 `START →（IDLE → LOOP）→（IDLE → LOOP）→ …`。

素材放在 `public/sprites/`，**排版不限單排或多排** —— 程式會從圖檔長寬比自動
推算幾欄幾排，匯出時不必遷就特定格式。詳細要求見該資料夾的 README。
**檔案不存在時會自動退回 `src/ui/CorgiDrawing.tsx` 的手繪 SVG**，遊戲照常能玩，
所以美術與程式的時程可以分開。要驗證播放機制，可以先產生測試圖：

```bash
python scripts/make-test-sprites.py         # 產生有編號的測試 sheet
python scripts/make-test-sprites.py --clean # 刪掉，恢復手繪備援
```

換新素材時通常需要先校正格線（產圖工具的輸出很少是像素對齊的）：

```bash
python scripts/normalize-sprites.py public/sprites/corgi-idle.png --cols 12 --rows 1
```

逐格播放用 CSS `steps(N, jump-none)`，走合成執行緒，求解器在算的時候也不會掉格。
多排的 sheet 用兩條動畫疊起來：橫向走完一排、縱向再換排。
`jump-none` 不能省 —— 細節見 `src/ui/CorgiSprite.tsx` 的註解。

## 用手機玩

`vite.config.ts` 裡設了 `server.host = true`，dev server 會綁 `0.0.0.0`，同一個 Wi-Fi 下的手機可以直接連：

1. 電腦上跑 `npm run dev`
2. 查電腦的區域網路 IP：`ipconfig`，找「IPv4 位址」（目前是 `192.168.1.106`，換網路會變）
3. 手機瀏覽器開 `http://<那個IP>:5173`

需要電腦開著、dev server 跑著、兩台在同一個 Wi-Fi。Windows 防火牆第一次可能會跳出詢問，要允許 `node.exe` 的連入連線。

樣式已針對觸控處理過：關掉雙擊縮放、關掉連點反白、hover 效果只在有滑鼠時套用、並套用 safe-area 避開瀏海與底部手勢條。

> 想要「隨時能開、不必開電腦」，下一步是部署到 Vercel／Netlify 並加上 PWA，手機就能加到主畫面、離線遊玩。真正上架 Google Play 需要 Android Studio；iOS 則必須有 Mac 與 Apple 開發者帳號。

## 關卡曲線

線性關卡制，盤面隨關卡變大、需要的推論也變深。開局是**空盤面**，不預先放柯基。

| 關卡 | 盤面 | 需要的推論技巧 |
| --- | --- | --- |
| 1–3 | 5×5 | 只需「某列／欄／區域只剩一格」 |
| 4–7 | 6×6 | 同上 |
| 8–11 | 7×7 | 需要「區域 ↔ 線」交叉排除 |
| 12–16 | 8×8 | 同上 |
| 17 | 9×9 | 同上 |
| 18 以後 | 10×10 | 基礎規則推不完，需要試誤 |

難度不是憑感覺標的，是用 `analyse()` 這個推論引擎**實際跑一遍**量出來的。

## 計分

第 k 隻柯基成功放下時得 `576 + 96(k−1)`，累計 `576n + 48n(n−1)`。常數與公式是從實機錄影的分數變化逐格反推的，在 9×9 與 10×10 兩關都相同，所以獎勵只跟「第幾隻」有關，跟盤面大小無關。失誤不影響分數。

連續放對 3 隻起開始出現稱號（Nice / Great / Perfect / Excellent / Amazing / Unbelievable），失誤會讓連擊歸零。

## 生命與存檔

每關三根骨頭。放下的柯基不在正解上就會**當場被拒絕**、變成紅色叉號並扣一根，扣完這一關重來。紅叉不能點掉也不能復原掉——命已經扣了，痕跡就該留著，而且那格「這裡不可能」的資訊本身有用。

進行中的盤面、已放的柯基、剩餘生命與分數都存在 localStorage，關掉重開會回到原本的局面。

## 關卡生成器怎麼運作

隨機畫色區再檢查有沒有唯一解是行不通的——實測 400 次只有 1 次會是唯一解。所以流程是**先有答案，再長出題目，最後修**：

1. **隨機挑一組合法解**。因為每列每欄各一隻，解必然是一個排列 `perm[row] = col`；規則 4 在排列下等價於「相鄰兩列的欄差 ≥ 2」。搜尋空間因此從 C(N², N) 縮到 N!，9×9 也能即時跑完。
2. **洪水填充長出區域**。以解的每一格為種子，偏袒面積小的區域先長，避免長出「一格區 + 巨獸區」。
3. **迭代修復成唯一解**。找出一組不是正解的解 S2，挑一格「S2 有、正解沒有」的位置，把它改劃給隔壁區域——那格搬進去之後，隔壁區在 S2 裡就變成兩隻柯基，S2 因此失效。被搬動的格子保證不是正解的柯基，所以正解完全不受影響。重複到唯一解為止。
4. **評難度**，不符關卡曲線的目標等級就換一張。

生成吃一個亂數種子，**同一個 seed 永遠產出同一張盤面**。這點是為對戰模式鋪路的：伺服器只要送一個 seed，雙方就能各自算出同一張題目，不必傳整張盤面。

目前共 30 關，全部通過 `npm run verify`。

## 放置驗證：兩層

這是跟一般 Queens 變體最大的差別。引擎手上有答案，會**即時比對**：

1. 先看有沒有跟既有柯基牴觸 → 能明確指出違反哪一條規則
2. 再比對是不是正解的格子 → 沒有規則可指，只能說「不對」

第二層的存在有直接證據：空盤面上放第一手也可能被拒絕扣命，那時不可能有任何規則衝突。因此玩家不可能走到「合法但推不下去」的死路，零失誤通關才有意義。

第一層的專屬回饋（規則卡高亮、金色衝突外框、大紅叉動畫）尚未實作，目前兩種失誤共用同一種呈現。
